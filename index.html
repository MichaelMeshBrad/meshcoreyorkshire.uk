  2. Add the public channel named #yorkshire.

Mobile setup · iPhone & Android

Choose a region for each channel.

#yorkshire is our main channel. Leave the client’s Default Region unset; choose the scope inside each channel instead.

1 · Open the channel

Connect and choose

Connect your phone to the companion by Bluetooth. Open Channels, then add or open the channel you want.

2 · Set Region Scope

Match the channel below

In the channel chat menu, choose Set Region Scope. Add the region if missing, then select it.

#yorkshire → yorkshire or eng-yh
#northwest → northwest
#northeast → eng-ne

3 · Check and chat

Say hello in #yorkshire

Check the selected region in the chat header, then send your name and general area. Repeat the scope setup for each channel you use.

Region names use lowercase and no #. Menu labels may vary by app version.

New to the mesh? If you hear others but your channel messages aren’t reaching them, check your channel scope first. Nearby users may still hear your unscoped messages directly and help you get set up. If you cannot reach anyone, email us for help. Official region guide →

Repeater configuration

Keep it simple. Keep it regional.

Use stock Repeater firmware from meshcore.io and the Yorkshire radio profile above. Leave other settings at their stock defaults. Every Yorkshire repeater must add these three regions, set its default to yorkshire and add region denyf * to block unscoped flood traffic. The older special configuration tweaks are no longer needed for this setup.

Required · repeater default yorkshire

Our main community region.

Required · Secondary Region eng-yh

Our secondary region.

Required · neighbouring region northwest

Routes across the Pennines.

Required · neighbouring region eng-ne

North East England routes.

Seven commands. One simple setup.

Apply to every Yorkshire repeater

On current stable stock firmware (v1.15.0 or later), log in and enter each CLI command separately. Check the responses, then save.

Required: add region denyf *
Run this command on every Yorkshire repeater, then run region save. It blocks unscoped flood traffic to reduce unwanted bot and spam traffic while keeping the three named regions available.

region put yorkshire
region default yorkshire
region put eng-ne
region put eng-yh
region put northwest
region denyf *
region save

Everyone’s repeater matters: consistent region settings help keep the network useful. Enter names exactly as shown, without #. The * means unscoped traffic; spam sent within an allowed region can still pass.

Quick help

Something not working?

Start with these checks. If you’re still stuck, ask in #yorkshire or email us.

Ask for help →
I can’t see any nodes

Check Companion firmware, Bluetooth, the antenna and all five radio settings. Leave the device powered for a few minutes near a window or outdoors.

I receive chat but mine doesn’t reach others

Check the channel’s Region Scope first: yorkshire, northwest or eng-ne. Then try a clearer location and test with a nearby contact. Reception alone does not prove a return path.

The flasher can’t find my board

Use Chrome or Edge on a computer, a USB data cable and the correct board model. A charging-only cable won’t work.

My repeater has poor coverage

Check antenna connections, power and nearby electrical noise. A clear, high position usually helps more than extra transmit power.

Useful extras

A few basics. When you need them.

Which device should I choose?

Phone companion: the easiest starting point; a supported Heltec, LilyGo or Seeed board connects over Bluetooth. Choose the 868 MHz version.

Standalone: a screen and keyboard device can work without a phone. Repeater: a fixed node extends coverage; it is not your personal chat device.

How do I test a new device?

Start with two companions a few metres apart. Match the radio profile, wait for discovery, exchange direct messages, then test #yorkshire with its region set. Increase distance only after that works.

RSSI measures signal strength; SNR compares signal with noise. Actual message delivery is the useful test.

Where should I put a repeater?

Choose a high, clear location with permission to install and maintain it. Use a suitable antenna, short feed cable and separation from electrical noise. Outdoor nodes need weatherproofing and reliable power.

What are adverts?

An advert introduces your node so others can discover it. Zero-hop adverts stay within direct range; flood adverts travel through repeaters. Send them sparingly and give the mesh time to respond.

How do I look after a repeater?

Record the board, firmware, radio profile, regions and power setup. Change the default admin password, keep access details secure and check weatherproofing and batteries. After updates, retest settings and two-way delivery.

Privacy and responsible use

Public channels are public: avoid personal or confidential information. Share precise locations deliberately and protect your node’s private key.

Use equipment within the UK licence-exempt power and duty-cycle rules. Antenna gain counts towards radiated power. This community network is not an emergency service or a replacement for 999.

What do the terms mean?

Companion: your messaging device. Repeater: forwards packets. Room Server: stores messages for collection. Region: limits where flood traffic is forwarded. Hop: one radio leg. Path: the route between nodes.
