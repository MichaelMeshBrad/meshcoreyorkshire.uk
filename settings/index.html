Repeater commands

Log in to your repeater’s CLI. Enter each command separately, in the order shown, and check each response.

region put yorkshire
region default yorkshire
region denyf *
region put eng-ne
region put eng-yh
region put northwest
region save
set flood.max.advert 10
set flood.advert.interval 35
set advert.interval 237

Companion: Settings → Network Settings → Default Region Scope → yorkshire. Return to Settings and tap ✓ to save.

If yorkshire is not listed

  1. On Select Region, tap + at the top right.
  2. In Add Region, tap Region Name and type yorkshire — lowercase, without a #.
  3. Tap the ✓ in the top-right app toolbar to add the region.
  4. On Select Region, select yorkshire.
  5. Return to Settings and tap its top-right ✓ to save.
